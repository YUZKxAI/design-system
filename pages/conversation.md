# Page Override — 会话页 (conversation)

> 本页覆盖 AI 会话界面的排布与流式规则。AI 行为模式见 `AI-PATTERNS.md`，组件见 `COMPONENTS.md`。

**页面：** 与智能体对话 / 多轮任务执行
**日期：** 2026-11-22

---

## 页面级说明

会话页是用户停留最久的页面。核心是**输出可读性**与**过程透明**：消息宽度受限，工具调用可展开，引用可追溯，输入框永远可达。

| 区域 | 规则 |
|------|------|
| 会话列表 | 280px（≥lg），xs–sm 隐藏并通过顶栏返回 |
| 主对话 | 消息最大宽 960px，居中，不随屏幕拉伸 |
| 引用区 | ≥1920 作为右侧面板，否则 Drawer |
| 输入框 | fixed 底部 + 安全区；窄屏附件收进"+" |

## 页面结构

1. 顶栏：会话标题 / 模型 / 分享 / 更多
2. 左栏：会话列表，按今天 / 昨天 / 近 7 天 / 更早分组
3. 主区：消息时间线 + 状态提示 + 工具调用 Trace
4. 右栏（宽屏）：引用来源 / 上下文用量 / 运行详情
5. 底部：PromptInput + 快捷操作

## 断点覆盖

| 断点 | 覆盖 |
|------|------|
| xs–sm | 列表隐藏；消息头像 24px；元信息换行；输入框 fixed |
| md | 240px 列表；引用收进 Drawer |
| lg–xl | 280px 列表；右侧引用面板可选 |
| 3xl+ | 会话 + 主对话 + 双引用区；消息仍 ≤960px |

## 交互要点

- 流式输出预留容器高度，光标 `steps(1)` 闪烁；用户上滑后停止自动跟随。
- msg 元信息显示模型名、时间戳、Token、耗时；助手消息固定"AI 生成 · 请核对"。
- 引用 chip 紧贴对应句子，点击打开来源 Drawer。
- 工具调用 Trace 默认折叠，运行时展开当前步；失败步保留原始错误。
- 停止生成保留已生成内容，标注"已停止于…"。
- 上下文达 92% 时顶部 Alert 提示压缩，压缩保留结论与引用。

## 状态覆盖

| 状态 | 表现 |
|------|------|
| 排队 | 三点脉冲 + 队列位置 |
| 思考 | "正在分析 {n} 份文档…" |
| 流式 | 文本 + 光标 + 已生成字数 |
| 完成 | 元信息行 + 复制/重试/反馈 |
| 失败 | 错误原因 + 失败步骤 + 重试，不清空现场 |

## 无障碍

- 新消息通过 `aria-live="polite"` 播报，流式期间节流，不逐字播报。
- 消息列表使用 `role="log"`，支持从末尾向前阅读。
- 停止生成按钮在流式期间保持可聚焦。
- 键盘：⌘/Ctrl+Enter 发送，Esc 关闭引用 Drawer。

## 技术约束

- 消息按会话 ID 隔离，切换会话保留滚动位置。
- 自动滚动仅当用户在底部附近时启用。
- reduced-motion 下流式文本一次性呈现，光标静态。
