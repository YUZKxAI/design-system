# Page Override — 控制台 (console)

> 本文件定义控制台外壳的页面级规则。令牌、组件、可访问性、响应式一律沿用 `MASTER.md`、`COMPONENTS.md`、`RESPONSIVE.md`。
> 本页不新增令牌，不新增组件变体。

**页面：** 智能体列表 / 运行监控 / 任务队列等主工作台
**日期：** 2026-11-22

---

## 页面级说明

控制台是信息密度最高的页面，默认使用 **comfortable** 密度，用户可手动切换 **compact** 并持久化。大屏（≥3xl）优先把空间分配给侧栏与辅助面板，而不是拉宽主内容。

| 区域 | 令牌 / 规则 |
|------|-------------|
| 侧栏 | `--sidebar-width` 240px；≥4xl 可到 280px |
| 顶栏 | `--topbar-height` 56px，sticky |
| 内容 | `--content-pad` 24px；≥xl 32px；最大宽按内容类型 |
| 背景 | `--bg-canvas`；内容表面 `--bg-surface` |
| 分隔 | 1px `--border-subtle`，不用重阴影 |

## 页面结构

1. 顶栏：面包屑 + 全局搜索入口 + 通知 + 头像
2. 侧栏：分组导航（≤5 组，每组 ≤7 项）+ 底部工作区切换
3. 主区：页面标题 + 筛选工具栏 + 内容区（表格 / 卡片 / 列表）
4. 右侧辅助区（≥1920 出现）：详情 / 引用 / Trace 面板
5. 底部：分页或批量操作栏，窄屏 fixed + 安全区

## 布局覆盖

| 断点 | 覆盖规则 |
|------|----------|
| xs–sm | 侧栏转顶部横向导航；辅助区收进 Drawer；筛选收进"筛选"按钮 |
| md | 64px 图标侧栏；辅助区仍收起 |
| lg–xl | 240px 侧栏；主区 + 可选右栏 |
| 3xl+ | 16–24 栏；侧栏 240–280px；主内容最大 1440px，剩余给辅助面板 |

## 交互要点

- 表格在 xs–sm 转卡片列表，状态与选中集合同步。
- 批量操作栏在选中项出现时才显示，提供"清除选择"。
- 排序、筛选、分页状态写入 URL，支持深链接与返回恢复。
- 危险批量操作走 L4 Dialog，显示影响条数与是否可撤销。
- 运行状态使用 AgentStatusBadge，必须带文字标签与耗时。

## 数据状态

| 状态 | 表现 |
|------|------|
| 加载 | 表格骨架行 / 卡片骨架，形状对齐真实内容 |
| 空 | 解释为什么为空 + 创建入口 |
| 错误 | 区分 403 / 404 / 500，提供重试或申请权限 |
| 部分失败 | 顶部 Alert 汇总，行内标记失败项 |

## 无障碍

- 侧栏导航使用 `nav` + `aria-current="page"`。
- 表格使用原生 `table` 语义，卡片列表使用 `role="list"`。
- 批量选择变化时通过 `aria-live="polite"` 播报已选数量。
- 筛选面板焦点陷阱，Esc 关闭后归还触发按钮。

## 技术约束

- 导航层级与 URL 路由严格一致，禁止视觉分组与路由不符。
- 所有列表数据源统一，卡片视图与表格视图不得各取一份。
