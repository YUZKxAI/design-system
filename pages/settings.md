# Page Override — 设置页 (settings)

> 本页覆盖设置类表单的排布、校验与危险区规则。表单校验规范见 `MASTER.md` §16。

**页面：** 账户设置 / 工作区设置 / 智能体配置 / 密钥管理
**日期：** 2026-11-22

---

## 页面级说明

设置页的核心风险是**误改与未保存**。分组必须清晰，危险操作必须隔离，离开页面前必须确认未保存内容。表单宽度受限，不随大屏拉伸。

| 区域 | 规则 |
|------|------|
| 分组导航 | 160px（md）/ 240px（lg+），xs–sm 转 Accordion |
| 表单区 | 最大宽 720px，左对齐，不居中拉伸 |
| 区块间距 | `--space-7` 48px，用标题分组 |
| 危险区 | 独立区块，红色描边，置于页面最底部 |

## 页面结构

1. 分组导航 / Accordion
2. 区块标题 + 说明
3. 字段组（标签 + 控件 + 帮助文本）
4. 保存栏：sticky 底部，显示未保存状态
5. 危险区：删除 / 重置 / 撤销授权

## 断点覆盖

| 断点 | 覆盖 |
|------|------|
| xs–sm | 分组转 Accordion，一次展开一组；保存栏 fixed + 安全区 |
| md | 160px 侧导航 + 表单 |
| lg+ | 240px 侧导航 + 720px 表单，右侧留白 |
| 5xl+ | 表单仍 720px，不拉宽；右侧可放"变更预览"辅助面板 |

## 表单规则

- 标签常驻可见，placeholder 不承担说明。
- 失焦校验单字段，提交校验全表，输入中不报错。
- 错误紧贴字段下方 + 顶部摘要（可点击定位）。
- 异步唯一性校验（如名称）需防抖 300ms，显示"正在检查…"。
- 服务端错误映射到具体字段，不只在顶部显示。
- Switch 只用于即时生效项；需要点保存的用 Checkbox。
- 密钥类字段默认遮蔽，需显式点击才显示。

## 危险区

- 独立 `DangerZone` 区块，标题与按钮使用 `--danger`。
- 删除类操作必须输入确认文本（如项目名）或走 L4 Dialog。
- 明确写出影响范围与是否可撤销。
- 禁止把危险操作塞进普通保存栏。

## 交互要点

- 有未保存改动时离开页面 → L4 Dialog 确认。
- 保存成功用 Toast（L3），不逐字段打勾。
- 自动保存的设置需标注"已自动保存"与时间。
- 重置按钮恢复上次保存值，不直接清空。

## 无障碍

- 每个字段组用 `fieldset` + `legend`，或 `role="group"` + `aria-labelledby`。
- 错误字段 `aria-invalid` + `aria-describedby`，焦点移到第一个错误。
- Accordion 分组使用 `aria-expanded`。
- 密钥显示切换按钮有 `aria-pressed` 与状态文案。

## 技术约束

- 表单状态与 URL 查询参数同步，便于分享具体设置项定位。
- 不保存密钥明文；前端只展示掩码与存在性。
