# Page Override — 仪表盘 (dashboard)

> 本页覆盖 Bento 仪表盘的排布与数据规则。令牌、组件、图表色板沿用 Master / RESPONSIVE / COMPONENTS。

**页面：** 概览 / 运行监控 / 成本分析
**日期：** 2026-11-22

---

## 页面级说明

仪表盘的目标是在一屏内回答三个问题：**现在怎么样、哪里不对、该去哪看**。默认 comfortable，大屏可用 compact。多出来的空间用于增加卡片数量，不拉宽单张卡片里的文字。

| 元素 | 规则 |
|------|------|
| KPI 卡 | 每卡 1 个指标 + 趋势 + 对比基准，禁止塞 3 个数字 |
| 图表卡 | 使用 `--chart-1..8` 顺序取色，图例双编码 |
| 状态区 | 异常项用 Alert L2，不用 Toast |
| 刷新 | 显示"更新于 30 秒前"与手动刷新按钮 |

## 页面结构

1. 页面标题 + 时间范围选择 + 刷新状态
2. KPI 行：3–4 张关键指标卡（xs 单列，sm 2 列，md 4 列）
3. 主图表区：趋势 / 分布，占 2–5 栏
4. 明细区：失败任务、成本排行、模型使用分布
5. 底部：跳转到完整列表的入口

## 断点覆盖

| 断点 | 卡片/行 | 图表 |
|------|---------|------|
| xs | 1 列，按重要性排序 | 单序列 + 文字表 |
| sm | 2 列，KPI 各占 1 | 主图占满 2 列 |
| md | 4 列，主图占 2 | 图例在下 |
| lg–xl | 8/12 列 | 2 图并排 |
| 3xl+ | 16–24 列，5–8 卡/行 | 3–4 图并排，KPI 卡仍 1 栏 |

## 数据规则

- **Y 轴从 0 起**，禁止截断制造趋势假象。
- 同比 / 环比必须标明基准周期（"较上周同期"）。
- 成本必须标注"估算"与币种；Token 用等宽数字。
- 饼图切片 ≤6，超出改为堆叠条形图。
- 图表必须提供加载（骨架）、空、错误三态，错误可重试。
- 时间范围切换后 URL 同步，刷新后保持。

## 交互要点

- KPI 卡可点击下钻，必须有 hover 边框变化与焦点态。
- 图表 hover 显示 tooltip（序列名 / 数值 / 单位 / 时间），键盘可达。
- 异常指标使用 Warning / Danger 色，但同时显示文字标签。
- 自动刷新间隔默认 60s；页面不可见时暂停，恢复后补一次。

## 无障碍

- 每张卡片有 `h3` 标题，屏幕阅读器可逐卡跳转。
- 图表提供隐藏的 `table` 等价数据；颜色不是唯一编码。
- 刷新状态用 `role="status"` 播报，不频繁打断。
- 趋势方向用箭头 + 文字，不只靠红绿。

## 技术约束

- 卡片顺序在 DOM 中即视觉顺序，禁止 CSS `order` 重排。
- 数据请求失败时保留上一次成功数据，并标注"显示的是 5 分钟前的数据"。
