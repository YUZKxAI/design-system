01

品牌 DNA

YUZK.AI 的界面不是"聊天窗口套壳"，而是一台面向智能的精密仪器。气质来自三个词：精度、信号、控制。电光蓝是唯一强调色，炭黑是默认底色，不需要第二种性格。

SIGNAL / 01

信号优先

任何像素都必须传递信息或承担操作。装饰不能争夺注意力，留白本身就是信息结构。

CONTROL / 02

确定性反馈

每次操作 100ms 内给出视觉回应。AI 的不确定必须被显式标注，而不是伪装成确定。

DENSITY / 03

密度可控

默认紧凑，用留白分组而非放大间距。用户可在舒适与紧凑密度之间切换。

绝对禁区：粉色系、糖果渐变、拟物阴影、无意义粒子动效、emoji 当图标。这套系统只有一种性格。
02

设计原则

六条按优先级排列的判定准则。当两条原则冲突时，编号小的优先。

#原则判定标准
01信号优先任何像素必须传递信息或承担操作；装饰不能争夺注意力
02确定性反馈操作 100ms 内有视觉回应；AI 的不确定必须显式标注
03信息密度可控默认紧凑、留白分组；提供舒适 / 紧凑两档密度
04一层一义同一视觉层级只表达一种语义；颜色、字号、位置不重复编码
05键盘等价所有鼠标可达的交互都有键盘路径与可见焦点
06渐进披露高级能力默认折叠，在上下文需要时才展开

10

可访问性

WCAG 2.2 AA 是底线，不是加分项。键盘、读屏、低视力用户必须能完成全部核心任务。

硬性指标
  • 正文对比度 ≥ 4.5:1，大字 ≥ 3:1
  • 焦点环 2px 电光蓝 + 2px offset，任何情况下不得移除
  • 触控目标 ≥ 44×44px，相邻间距 ≥ 8px
  • 图标按钮必须有 aria-label
  • 表单错误 aria-invalid + aria-describedby 且贴近字段
  • 状态 不只靠颜色表达，必须配图标或文字
  • 缩放到 200% 无横向滚动
Focus ring · 用 Tab 键体验
焦点测试 C
本手册支持键盘导航：Tab / Shift+Tab 移动焦点，⌘/Ctrl + K 唤起命令面板，Esc 关闭。请实际按一遍再交付你的产品。
11

内容与语气

中文为主，技术名词保留英文原词（Agent、Token、MCP）。句子短、动词开头、去掉客套话。

DO · 推荐

  • 按钮用动词短语："创建项目"、"重试调用"
  • 错误结构：发生了什么 + 为什么 + 怎么办
  • AI 结果固定标注"AI 生成 · 请核对"
  • 数字用等宽字体，单位与数值间留半角空格：24 px、1.5 s
  • 状态文案具体："正在调用 3 个工具…"

DON'T · 禁止

  • "确定"、"提交"、"好的"等无信息量按钮
  • "亲"、"您好呀"、"抱歉给您带来不便"
  • 笼统的"加载中"、"操作失败"
  • 把 AI 推测包装成确定事实
  • 连续感叹号与营销腔修饰词

    --duration-normal240msModal / Drawer / 列表进出场
    --duration-slow360ms复杂编排，超过则拆分为阶段
    AI 场景语义

    thinking

    低频呼吸，不做永久循环；超过 2 秒应显示阶段文本。

    streaming

    增量出现，保留已生成内容；停止生成不应清空。

    tool call

    阶段指示 + 耗时，不隐藏工具名称。

    approval gate

    静止高亮 + 明确动作，禁止闪烁催促。

    reduced-motion：保留终态与状态差异，去除位移、缩放和循环动画。

    主题与令牌治理

    令牌是设计系统的唯一接口。四层模型：品牌配置 → primitive → semantic → component，组件只引用语义层。完整规范见 THEMING.md §5.6–5.9。

    brand config 品牌配置端

    8 个 --brand-* 槽位。唯一允许人工改色的地方，换品牌只改这里。

    primitive 原语层

    色值、间距、字号的原始定义，不直接给组件用。

    semantic 语义层

    bg / text / border / action / state，主题切换的唯一作用面。

    component 组件层

    组件专属映射，引用语义层，禁止跨层与裸 hex。

    品牌色切换 · 8 槽位驱动 31 处语义声明
    data-brand="yuzk（默认）"
    切换后同步变化：主按钮 / 焦点环 / 链接 / 选中态 / 图表首序列 / 品牌柔光。四套均已按 AA 实测（§5.8 九项，最低 4.54:1）。默认品牌无需 data-brand，其余挂在根元素 <html data-brand="…">，且必须给全 8 个槽位。
    唯一强调色：默认品牌亮色 --brand-700 #2455B4、暗色 --brand-500 #4C8DFF；#4C8DFF 上禁止白字。整包替换允许，第二强调色禁止——同一产品只允许一个品牌生效，不得与蓝并存。弃用令牌需共存一个版本 + 迁移映射后再移除。
